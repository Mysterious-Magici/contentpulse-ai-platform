# ContentPulse AI — AI-Powered Content Generation & Analysis Platform

Flagship **Module 14 Capstone Project** combining **Python AI/ML, Data Science, and the MERN Stack** to help small businesses generate high-converting marketing copy and analyze content performance at **₹0/$0 infrastructure cost**[cite: 1, 29].

## Live Demo & Hosting
* **Live Web App (Vercel):** `https://contentpulse-ai.vercel.app`[cite: 1, 29]
* **Live Backend API (Render):** `https://contentpulse-ai-api.onrender.com`[cite: 1, 29]

## Key Features
* **Prompt-Engineered AI Content Studio:** Generates tailored Instagram posts, emails, Google ads, product descriptions, and blog intros via Groq Free API[cite: 2, 29].
* **Real-Time NLP Analyzer:** Computes Flesch Reading Ease, sentiment polarity, top keywords, and SEO readiness score (0–100)[cite: 2, 29].
* **Python Data Science Pipeline:** Cleans campaign datasets with Pandas and exports visual KPI charts using Matplotlib and Seaborn[cite: 2, 29].
* **Interactive MERN Dashboard:** Persists campaigns in MongoDB Atlas and renders live Recharts analytics[cite: 2, 29].

## Tech Stack (100% Free Tier)
* **AI / ML:** Groq Cloud API (`openai/gpt-oss-20b`), Python 3.11+, FastAPI[cite: 3, 29]
* **Data Science:** Pandas, Matplotlib, Seaborn[cite: 3, 29]
* **MERN Stack:** MongoDB Atlas (M0), Express.js, React 18 (Vite), Node.js, Recharts[cite: 3, 29]
* **Hosting:** Vercel (Frontend) + Render (Backend)[cite: 3, 29]
